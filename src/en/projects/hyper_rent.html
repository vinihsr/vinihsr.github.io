Hyper-Rent is a vehicle rental management system designed to act as a data extraction source (Data Source). Besides the transactional portal for customers, the application includes an admin panel focused on governance and on distributing metrics through secure integrations.

Architecture and Tech Stack

The application follows a modular model with a reverse proxy for load balancing and route isolation:

{% codeblock "text" %} Hyper-Rent/ ├── client/ # Interface (React) ├── server/ # Backend API (Express / Node.js) ├── nginx/ # Reverse Proxy and Gateway (Nginx) └── package-lock.json {% endcodeblock %}

Core Modules (Data Engineering)

  • API Key Management: Internal engine for creating, authorizing, and revoking encrypted keys, enabling secure endpoint access for external partners or extraction pipelines (ETL/ELT).
  • Aggregated Data Delivery: Endpoints designed to serve pre-processed, summarized data (e.g., occupancy rate, cars by year/model), reducing the analytical load on the operational database.
  • Compliance Filter (LGPD): Implementation of opt-in rules integrated with the Terms and Conditions (T&C). The API programmatically restricts the data it returns, exposing only the transactional records of customers who have authorized their use for analytical purposes.
