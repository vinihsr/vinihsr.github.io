The Databricks Finance Pipeline is a data engineering project focused on ingestion, processing, and structured analytical modeling. It consumes two years of stock history from the largest banks (JPM, BAC, GS, C, WFC) through the yfinance API, handling the entire data lifecycle inside the Databricks ecosystem.

Medallion Architecture

The data flow was designed to separate responsibilities, ensuring that raw data is preserved while the subsequent layers apply quality and business rules:

{% codeblock "text" %} yfinance API → Bronze (Raw) → Silver (Clean) → Gold (KPIs) → Dashboard {% endcodeblock %}
  • Bronze Layer (Ingestion): Download and storage of raw data exactly as provided by the source, serving as an immutable history.
  • Silver Layer (Transformation): Cleaning, type casting, and data validation using the distributed processing power of PySpark.
  • Gold Layer (Business): Feature engineering and consolidated financial metrics, including daily return percentage, 7-day moving average, and price range variation.

Notebook Structure

The local orchestration (Databricks Free Edition) is split into the following independent routines:

{% codeblock "text" %} Notebooks/ ├── 01_bronze_ingest.py # Data extraction via yfinance and persistence ├── 02_silver_clean.py # Data cleaning and schema validation ├── 03_gold_transform.py # Financial KPI calculations └── 04_analyze.py # Analytical queries (Databricks SQL) and Dashboard {% endcodeblock %}

Consumption Layer

The final stage of the pipeline delivers the modeled data (Delta Tables) directly to Databricks SQL, enabling financial market trend visualization through integrated dashboards.
